# 实施路线图

每个里程碑都是可演示、可测试、可回滚的纵向切片；未通过验收不进入下一阶段。首期不删除最终能力，但不要求在首个闭环同时完成全部家庭、隐私与内容能力。

| 里程碑 | 可交付闭环 | 验收与主要风险 | 回滚 |
| --- | --- | --- | --- |
| M0 设计冻结 | 本文档集、ADR、术语、不变量和验收清单 | 跨文档同一规则只保留一个数值/状态定义；风险是范围漂移 | 仅文档变更 |
| M1 身份与单家庭训练 | 邀请注册、已验证家长、一个学生、双向关联、一个反应力训练、最小审计 | 未接受不得访问；关联码不可复用；训练结果可重读；风险是身份/授权错误 | 关闭注册，撤销邀请码，回滚应用 |
| M2 计划与固定积分闭环 | 单正式计划、单时间点日程、系统完成事实、固定模板、唯一流水与余额 | 重试不重复日程/积分；计划边界正确；风险是时间与幂等 | 停用计划/模板，用反向流水修正 |
| M3 账本与后台可靠性 | 规则版本、人工事实确认/更正、outbox、Worker、投影重建 | 事实更正冲销正确；死信可告警和重放；风险是异步重复/遗漏 | 停止消费者，从权威记录重建投影 |
| M4 多家长与细粒度授权 | 多学生家庭、部分解除、授权纪元、私密总结逐家长授权 | 解除后即时拒绝；其他关系不受误影响；风险是撤权陈旧 | 停止关系写入，修复关系/授权投影并审计 |
| M5 训练扩展与趋势 | Stroop、数字广度、版本/年龄档分段趋势、移动与键盘验收 | 每日有效资格按 training key；跨版本不比较；风险是计时失真 | 停用训练定义版本，保留原始记录 |
| M6 生命周期、兑换与联合验收 | 兑换、导出、删除/tombstone、容量与恢复演练 | 兑换扣减唯一；导出范围正确；恢复不复现删除内容；风险是隐私与恢复 | 关闭功能开关，停止导出/删除执行队列 |
| M7 延后功能试点 | 错题或家长推送二选一 | 另立需求和媒体安全验收 | 功能开关关闭 |
| M8 AI/语音 | 暂不排期 | 需独立需求、授权、安全和供应商 ADR | 不启动 |

## 已决事项与上线前阻断项

已决：首期中国大陆优先、5–18 岁、固定 `Asia/Shanghai`、邀请制、家长验证、管理员 TOTP、家庭单活跃归属、家长配置所有权、MVP 不接 AI/语音。

上线前阻断项：目标地区未成年人数据和监护同意合规评审、隐私政策/同意证据方案、生产厂商 DPA 与数据驻留核验、恢复演练、紧急访问双人审批流程和容量/SLO 验收。它们不是“待确定产品需求”，而是上线门槛。

## 每个里程碑的共同工作顺序

1. 从本设计文档集提取相关不变量和失败路径。
2. 先实现数据迁移、Module Interface 与数据库级唯一约束。
3. 再验证 Module Interface、事务/outbox 和投影重建；最后验收跨 Module 用户流程。
4. 验证桌面与移动断点、服务端权限、幂等重试、失败路径、审计和回滚。
5. 输出测试证据、未验证项、监控指标和回滚说明。

## 关键验收场景

- M1：一个已验证家长与学生完成双向关联；拒绝、过期或重复关联码不产生任何访问权。
- M2：家长建立“每天 20:00 完成作业”的正式计划；学生完成后只生成一条可解释的积分流水。
- M3：更正已确认错误数后，原积分被反向冲销，新结算只生成一次；Worker 重试不造成重复流水。
- M4：一个家长解除与某学生的关系后立即不能读取该学生私密资源，但仍可访问自己与同家庭其他学生的有效关系范围。
- M6：家长导出仅包含当前授权数据；删除执行、备份恢复和 tombstone 重放后已删正文不再可读。
