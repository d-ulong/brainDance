# 产品范围与验收标准

## 0. 资源架构约束

术语以 `CONTEXT.md` 为准，权威持久化模型以 `data-model.md` 为准。本文件只描述用户可见结果：亲子协作授权的权威事实是生效关联，不是成员列表；敏感读取必须实时重新授权；计划、事实、结算和流水均保留历史版本；余额、成员、首页和趋势是可重建投影。

首个可用 MVP 闭环限定为：一个已验证家长、一个已关联学生、反应力训练、一个正式计划的单时间点日程，以及一个固定积分模板。其他已确认能力不删除，但按 `implementation-roadmap.md` 分阶段进入。

## 1. 产品目标

本产品是一个仅面向家庭协作的学习与认知训练平台，首期学生年龄范围为 5 至 18 岁。学生完成训练和计划任务，系统留下可解释的记录；家长在学生授权与最小可见范围内，陪伴、制定规则和复盘。脑力训练参考 Brainlab 的“选择 → 行动 → 留痕 → 复盘”节奏，但不做医学、智力或认知诊断。

MVP 的成功标准是：一个已关联的学生能完成训练与日程任务，家长能看见约定范围的进展，积分规则能以可追溯方式结算。

首发采用管理员邀请码的封闭测试，不开放公开注册或可被搜索引擎索引的注册页；验证家庭真实闭环后再评估扩大。

学生首页默认只展示今天待做日程、今日有效训练、当前积分和最近一条个人趋势；家长首页按学生分卡展示今日执行概览、训练汇总、待确认事实/兑换和最近普通总结，私密总结仅在已有授权时显示。

## 2. 角色与职责

| 角色 | 职责 | 不能做的事 |
| --- | --- | --- |
| 管理员 | 创建/撤销邀请码；管理训练目录、积分规则模板与系统配置；查看安全审计 | 不应默认浏览家庭的私密总结、作答内容或媒体 |
| 家长 | 用邀请码注册；发起或接受关联；为已关联学生创建目标、计划、日程、积分规则和推送；查看授权范围内的进度 | 不可修改学生历史训练原始记录；不可单方建立关联 |
| 学生 | 用邀请码注册；发起或接受关联；创建个人目标和计划；完成训练与日程、查看自身积分；提交每日总结与推送作答 | 不可管理他人、不可自行改变积分规则或关联状态 |

## 3. 家长—学生双向关联流程

1. 学生本人登录后主动生成短时、一次性的学生关联码/二维码；家长输入或扫码后发起申请。系统不提供按学生姓名或账号搜索的入口。
2. 系统校验双方角色互补、关联码有效、账号有效、没有相同生效关联，且学生没有其他活跃家庭；创建 `pending` 申请并通知学生。
3. 学生必须在本人已登录账号中查看发起人、可见范围和说明后，选择接受或拒绝；家长不能代替学生确认。
4. 学生接受时以事务创建 `active` 关联；若尚无活跃家庭则自动创建家庭，否则加入既有家庭；写入家长发起时间、学生确认时间和审计事件。拒绝则保留拒绝原因（可选）但不建立关系。
5. 任一已关联家长或学生可单方立即解除；系统立即撤销对方访问权并写审计记录。管理员只可在安全/申诉情形下强制解除，并必须留审计记录。

学生关联码有效 10 分钟、仅能使用一次；学生可随时使其失效，同一时间最多保留一个有效码。关联申请在 72 小时后自动过期，家长需使用学生重新生成的关联码再次申请。

解除关联后，离关联家长创建的未完成正式计划、积分规则和兑换内容自动停用；历史保留，其他家长不能接管编辑。该家长获得的私密每日总结授权立即撤销，重新关联也不自动恢复。

最后一位家长解除关联后，学生账号与历史保持可用，学生可继续自主训练、创建和执行个人计划；但家庭不再有家长协作、配置或监督。

无家长学生仍可生成关联码并确认新家长加入原家庭；若此前从未有首位家长，新家长首次关联仍须完成监护同意留存。离关联自动停用的正式计划、积分规则和兑换内容不会因原创建家长重新关联而自动恢复，只能由该创建家长逐项手动启用并写审计。最后一位家长离开时，待处理兑换申请自动取消且不扣积分，兑换目录保持停用。

已确认：一个家长可在同一个家庭管理多名学生，但 MVP 中同时只能属于一个活跃家庭；一个学生可关联多位家长，但同时也只能属于一个活跃家庭；首次生效关联自动创建家庭，后续关联加入该家庭。MVP 中家庭成员统一使用且不可修改 `Asia/Shanghai` 时区。MVP 不实现家庭之外的组织、监护权校验或家长之间的自定义权限分级。

配置所有权例外于共同家长权限：创建目标、计划或积分规则的家长是该配置的唯一编辑者；其他已关联家长只能查看，并可补充学生日程的执行记录，不能修改、停用或删除配置。

## 4. MVP 范围

### 4.1 账号与关联

- 管理员独占生成、撤销带角色、有效期、使用次数限制的邀请码的权限；家长不能自行生成邀请码。家长与学生邀请码默认 7 天有效，管理员邀请码默认 24 小时有效；管理员可设置更短期限与单次或限定次数。
- 家长和管理员通过邀请码注册；5–12 岁学生由已注册家长创建受控学生账号并配置登录方式；13–18 岁学生可用管理员发放的学生邀请码自行注册；两类学生首次登录后均由本人确认关联。
- 家长和管理员使用手机号或邮箱加密码登录；学生使用用户名加密码登录。5–12 岁学生由家长设置初始密码，首次登录后由学生自行修改。
- 创建学生账号时收集完整出生日期，仅用于年龄档和合规判断，家庭内默认不展示；只能由管理员按纠错流程修改并审计。
- 家长使用的手机号或邮箱必须完成验证码验证后才激活账号；未验证家长不能发起关联或访问学生数据。管理员登录必须完成密码与 TOTP 双因素认证。
- 首位超级管理员仅由生产环境受控初始化配置创建，系统不开放公开管理员邀请码；后续管理员只能由现有管理员创建邀请码邀请，所有提权操作写审计。
- 同一账号连续 5 次登录失败锁定 15 分钟，并按 IP 与账号做速率限制；锁定和解锁写安全审计。学生不能自行改用户名，仅管理员按纠错流程处理。学生改密或被家长/管理员重置密码后，其余会话立即失效。
- 家长更换手机号或邮箱须验证新联系方式；旧联系方式可用时还须确认，不可用时由管理员人工核验；变更后使其他会话失效。
- 家庭内仅展示显示名，学生登录用户名不向其他成员公开，真实姓名不是必填资料。关联双方可查看与自己相关的关联历史（显示名、开始/结束时间、结束操作者），但不能以此恢复访问权或查看对方后续信息。
- 对 5–18 岁学生账号，任意已关联家长或管理员可重置密码；重置后学生下次登录必须自行修改，且重置写入审计日志；MVP 不提供学生自助找回。
- 首位家长创建学生账号或首次关联学生时，必须确认并留存版本化的监护同意与隐私政策；后续加入家长仅确认本人条款同意。
- 三角色退出、基础资料。
- 双向确认关联、解除关联、权限检查和审计。
- 学生或任一已关联家长可发起账户或内容删除请求；请求立即冻结访问、保留 30 天撤销期。学生账户或学生内容的最终删除须学生本人确认，管理员可在安全或法定请求情形强制执行。
- 学生可导出本人全部数据；家长仅导出当前获授权范围内学生数据，私密总结仅在对应授权存在时包含。导出链接一次性且有效 24 小时。

### 4.2 脑力训练

- 首批且仅首期上线三项标准训练：反应力、Stroop 抑制、数字广度（顺背/倒背）；其余训练游戏延后。
- 训练定义、一次会话、指标、个人最佳、近 7 天覆盖和趋势。
- 训练结果只归属于学生；家长默认读取训练汇总，需要时可主动查看详细训练记录，无需学生逐次授权。
- 趋势默认近 7 天，可切换近 30 天和全部历史；训练定义版本或年龄档变化必须分段说明，不做跨段连续比较。
- 三项训练按 5–8、9–12、13–18 岁分档提供题目池、说明文案和默认难度；趋势只在同一训练定义版本与年龄档内比较，不跨档排名。
- 计时训练失焦时暂停；累计失焦超过 30 秒或恢复失败则为放弃会话，不计趋势或积分但保留诊断。每项训练每日仅首条有效完成会话计入趋势与积分，其余为练习。
- 反应力展示正确反应中位反应时与准确率；Stroop 分别展示一致/不一致试次表现及个人干扰差值；数字广度分别展示顺背/倒背最长连续正确位数和每档尝试结果。所有结果明确为训练记录，不构成医学或智力评估。
- 年龄档在学生生日跨档后的次日生效，历史趋势按档位分段展示；三项训练均支持触控/鼠标点击和键盘 `Space`/`Enter`，不依赖拖拽或音频输入。

### 4.3 目标、计划与日程

- 目标：名称、说明、开始/截止日期、状态。
- 学生可创建个人目标和计划；家长可将其转化为正式计划，转化永不覆盖原始个人计划，只保留来源关系。
- 学生可在转化后继续编辑或关闭原始个人计划；该变更不修改已生成的正式计划。
- 正式计划：每日、每周、每月、每年或指定星期几的规则；每份正式计划只归属于一名学生。学生个人计划默认对所有关联家长可见，家长只可查看、补充执行记录或转化为正式计划，不能直接编辑。
- 日程：由计划版本和稳定时间点生成，也支持手动创建；学生可创建个人手动日程，关联家长可创建归其所有的手动日程；手动日程不触发积分。正式计划可在一天生成多个独立实例，每一实例拥有独立的稳定键、状态、事实和结算。日程可标记完成、跳过或过期；跳过原因可选、记录操作者和时间，且永不产生正向积分。
- 编辑正式计划的频率或时间仅从次日起以新计划版本生效：当天及历史实例不变，未来未完成实例撤销后按新实例键重建；停用或删除计划时，未来未完成实例标为 `cancelled` 而不物理删除。
- 提醒 MVP 仅使用站内通知中心；正式计划由创建家长设置提醒、学生个人计划由学生设置，默认关闭。邮箱/手机验证码仅用于账户安全，浏览器、短信和微信等业务推送延后。
- 未来如接入系统级推送，只能显示通用提示，不得泄露计划名称、每日总结、积分或私密内容。
- 每日总结：MVP 仅支持文本，每名学生按家庭日期最多一条；当天可编辑或删除。普通总结默认对所有已关联家长可见且不能改为私密；学生可标记私密总结并按家长逐一授权、随时撤销特定家长授权，私密总结可主动改为普通总结。新关联家长可看保留的普通历史，私密历史不自动开放。学生删除时立即撤销访问并删除正文，仅留无正文审计；不支持图片、音频、附件、语音转写、AI 总结或家长评论。

### 4.4 积分

- 管理员维护系统积分规则模板；家长仅可基于模板为已关联学生调整允许的阈值、分值、适用计划、生效日期和每日上限；学生只读，不开放自由条件树或脚本。首批模板为：（1）开始时间 + 耗时 + 错误数/错误率；（2）累计达成数或连续达成数；两者均支持基础分与额外条件加分。
- 系统记录的完成时间可直接结算；学生自报的错误数等人工事实必须经任意一位已关联家长确认后才能结算。
- 以版本化日程事实触发结算；系统事实可立即确认，人工事实须关联家长确认。结算在同一事实版本、规则版本和结算周期内唯一，随后才产生不可变流水与余额投影。
- 记录不可直接篡改的积分流水；任意已关联家长可更正人工事实，系统以反向流水和新结算结果修正积分。
- 家长配置可兑换内容；学生发起兑换申请，任意已关联家长确认后才扣减积分。
- 兑换内容仅含名称、所需积分、简短说明和启用状态，线下兑现；不接图片、库存、物流或支付。创建家长可设置每名学生每月单项兑换次数，默认不限。
- 学生标记日程完成时，规则若只依赖系统事实则自动结算；依赖错误数等人工事实时等待家长确认。
- 历史更正导致已兑换积分被收回时允许余额为负；负余额禁止新兑换，后续获得积分优先抵消负数。规则编辑仅作用于此后新事实，历史保留原规则版本。
- 日程允许在计划日次日结束前补记为迟完成并记录真实完成时间；超过窗口自动过期，积分规则可选择是否奖励迟完成。
- 学生个人计划的日程完成不触发积分；仅家长创建或转化后的正式计划可作为积分结算输入。目标仅由创建者手动完成或关闭，单次日程完成不自动关闭目标。
- 同一完成事件默认只结算优先级最高的一条规则；仅管理员模板明确可叠加时可多条结算。模板定义不可突破的上限，家长可设置更低的单日奖励次数或分值。
- 任一关联家长可发放一次性手动奖励，必须填写原因和金额、写入不可变流水并通知所有关联家长；不允许家长临时惩罚性扣分。负向流水仅来自已批准兑换、事实更正，或管理员模板事前定义并由家长启用的未完成/未达标扣分规则。
- 学生可点击日程“开始”与“完成”以记录系统真实时间，也可手动补填开始、结束或耗时；手动事实用于积分须经任一关联家长确认。补填次数按每名学生、每家庭自然月全局计算，家长可在 0–10 次内设置，默认 5 次、不结转，管理员设系统硬上限；计划日次日 `18:00` 后才录入的事实不产生正向积分。已启用扣分模板的正式计划在该时点对未完成或已确认未达标自动扣分，未填报不能避免扣分。迟完成默认计入累计达成、但中断连续达成；模板可显式允许不断连。
- 次日 `18:00` 后补填“当时已完成”仅补充档案，不能撤销既有扣分，除系统错误或正式事实更正。完成但缺计时质量事实默认不奖励，只有模板明确字段缺失为未达标条件时才扣分；待家长确认的错误数据不奖不扣。同一规则、日程实例和结算周期奖扣互斥。模板定义单次和每日最大扣分上限，家长只能设更低值；每次扣分通知学生与所有关联家长规则名称和原因。
- 学生可撤销待审批兑换申请，不扣分并留历史；家长拒绝时必须填写对学生和关联家长可见的简短原因。申请提交时快照所需积分，后续目录调价只影响新申请。
- MVP 不提供徽章、连续打卡火焰或家庭内部排行，仅保留积分和个人趋势。仅训练会话支持短暂断网后的安全重试与去重；日程、积分、关联和删除必须联网，失败时明确未提交。
- 日程完成不要求也不支持证明附件，仅记录系统时间、手动事实与家长确认。学生或关联家长可在计划日后 7 个家庭自然日内发起正式事实更正；超期仅管理员可基于安全或数据纠错处理，均以新事实版本与反向流水修正。

## 5. 延后范围

- 全部其余训练游戏、排行榜和“脑年龄”指数；首期只做个人趋势和家庭复盘，不做公开竞技。
- 错题库、家长推送、手写作答、评论、知识点与方法论内容库。推送试点支持文本、链接和图片；视频来源治理暂不处理；学生作答支持文本、图片和手写图片；评论仅限家庭内。
- 语音转文字、每日 AI 总结、自学方案和按角色/账号路由的大模型调用。
- 原生 App、短信/微信提醒、支付/积分商城、多人家庭组织。

## 6. 明确不做

- 医学诊断、心理评估、智商测定或治疗建议。
- 在未事前启用、无清晰条件与无可解释流水的情况下，以学生表现自动作出惩罚；以及任何学业结论或高风险推荐。
- 未经学生和关联范围授权的内容共享。
- 在 MVP 中执行复杂的可视化规则脚本或允许用户编写任意代码。

## 7. MVP 功能验收

| 功能 | 可验收结果 |
| --- | --- |
| 邀请码注册与学生开户 | 有效邀请码只允许目标角色使用；过期、耗尽、撤销的邀请码被拒绝；5–12 岁学生仅能由已注册家长创建受控账号，13–18 岁学生可自行使用学生邀请码注册；首次登录后均需本人确认关联 |
| 年龄变化 | 学生 12 岁满 13 岁时不自动迁移账户，不自动改变关联家长或管理员的密码重置权限 |
| 年龄上限 | 学生满 19 岁后账号、余额与历史可保留查看，但系统拒绝新增训练、目标、计划、日程、积分事实与兑换；未来未完成日程取消，并提示导出或归档 |
| 登录 | 家长/管理员仅接受手机号或邮箱加密码；学生仅接受用户名加密码；5–12 岁学生首次登录必须修改初始密码；各账户凭据相互独立 |
| 账号安全 | 家长须先验证手机号或邮箱才可激活和访问；管理员密码登录后必须通过 TOTP；首位超级管理员仅能受控初始化 |
| 凭据安全 | 家长/学生邀请码默认 7 天、管理员邀请码 24 小时；连续 5 次失败锁定 15 分钟；换绑验证并撤销会话；学生用户名仅可受控纠错 |
| 删除、导出与保留 | 删除请求先冻结 30 天，学生内容最终删除须学生确认；导出严格按当前授权范围；主存储期满删除、备份最长 90 天、安全审计默认 3 年 |
| 受控密码重置 | 任意关联家长或管理员可重置 5–18 岁学生密码；MVP 不提供学生自助找回；重置记录审计并强制学生下次登录修改 |
| 双向关联 | 未接受前双方不能互看数据；学生必须在本人账号中确认；接受后权限即时生效；拒绝/解除后访问立即失效 |
| 关联码时效与无家长状态 | 关联码 10 分钟有效、一次性且同一学生至多一个有效码；申请 72 小时过期；最后一位家长离开后学生仍可自主训练和计划 |
| 关联码与监护同意 | 仅学生可主动生成短时一次性关联码；系统不可按姓名/账号搜索学生；首位家长的监护同意和隐私政策版本可审计留存 |
| 训练 | 三项训练均可完整运行；每次结果含原始指标与训练定义版本；刷新和重新登录后记录仍在 |
| 训练适龄与中断 | 按三个年龄档加载难度；失焦超 30 秒或恢复失败标为 abandoned；每项每日仅一条有效会话计趋势与积分，其余为练习 |
| 训练指标 | 反应力以正确反应中位时和准确率计；Stroop 保留两类试次和干扰差值；数字广度分开记录顺背/倒背最长连续正确位数；均不做医学、智力或跨学生排名 |
| 首页与趋势 | 学生首页聚焦今日行动；家长按学生分卡陪伴；趋势默认近 7 天并按版本/年龄档分段；没有家庭比较或游戏化排行 |
| 弱网 | 仅训练会话支持短暂断网安全重试；日程、积分、关联与删除需联网并在失败时明确未提交 |
| 首发与分析 | 首发仅邀请码封闭测试；MVP 不接第三方用户行为分析，仅保留自有系统最小化聚合指标 |
| 年龄与输入 | 出生日期仅用于年龄档与合规；跨档次日生效且趋势分段；训练可通过触控/鼠标或 Space/Enter 完成 |
| 提醒与通知 | MVP 仅有默认关闭的站内提醒；提醒归计划创建者或学生所有；未来系统推送只可使用不含业务内容的通用文案 |
| 训练档案 | 正确展示个人最佳、近 7 天覆盖、趋势缺失状态；不把训练结果解释成医学结论 |
| 计划与日程 | 学生可创建个人计划；家长可转化为保留来源的正式计划；每份正式计划只归属一名学生；正式规则可生成正确日期的实例；手动日程不被重复生成；状态变更具备时间和操作者 |
| 计划变更 | 家庭时区固定为 Asia/Shanghai；正式计划编辑从次日重建未来实例；停用计划将未来未完成实例标为 cancelled，历史保留 |
| 手动日程与更正 | 学生或关联家长可创建不计分的手动日程；正式计划可每日多实例；无证明附件；日程事实 7 个家庭自然日内可正式更正 |
| 个人计划与成年 | 个人计划默认对关联家长可见但不可被其编辑，且不触发积分；目标由创建者手动关闭；满 19 岁后取消未来日程并停止兑换 |
| 积分 | 管理员可维护模板、家长可为关联学生创建规则和兑换内容、学生只读；同一事实重复提交不会重复结算；任意关联家长可更正人工事实；学生兑换必须经家长确认，调整不会改写原流水 |
| 积分边界 | 规则编辑仅影响新事实；历史更正可导致负余额并冻结兑换；次日结束前可补记迟完成，规则可选择是否奖励 |
| 积分模板与调整 | 家长仅在模板参数内配置；默认取最高优先级规则，模板可显式允许叠加；允许有原因的手动奖励，不允许临时惩罚性扣分；模板限制每日奖励上限 |
| 兑换 | 仅线下文本目录；可设每学生每月次数；学生可撤销待审批申请；拒绝须说明；审批按申请价格快照扣分 |
| 执行时间与补填 | 开始/完成可由系统记录或手动补填；手动计分须家长确认；家长可设每月补填配额（默认 5 次），次日 18:00 后补填不产生正向积分；已启用模板对未完成/未达标任务自动扣分 |
| 每日总结 | 每家庭日期一条、当天可编辑；普通总结对所有关联家长与新关联家长可见且不可转私密；私密总结仅对学生和逐一获授权家长可见，授权可随时撤销，转为普通后向所有当前关联家长开放 |
| 总结输入与删除 | MVP 仅支持文本且不支持家长评论；学生删除后正文不可再读、主存储删除，仅保留无正文审计 |
| 权限 | 学生无法访问其他学生；家长仅能访问生效关联及授权范围内的数据；非创建家长不能修改目标、计划或积分规则；管理员动作可审计 |
| 管理员边界 | 管理员不代操作家庭业务；默认不可见私密数据。紧急访问须理由、范围、时长、双管理员批准与完整审计 |
| 离关联处置 | 离关联家长创建的未完成正式计划、积分规则和兑换内容自动停用；历史保留且不可被其他家长接管；私密总结授权立即撤销 |
| 无家长与重新关联 | 学生仍可生成关联码邀请新家长；原创建家长重新关联后可逐项手动启用旧配置但不自动恢复；待处理兑换申请自动取消且不扣分 |

## 8. 待确认问题与推荐默认值

| 问题 | 推荐默认值 |
| --- | --- |
| 学生年龄范围 | 已确认 5–18 岁；上线前必须完成监护同意、隐私政策、年龄适配和目标地区合规评审 |
| 家长可见内容 | 所有已关联家长默认可见训练汇总、日程状态、积分、普通每日总结和推送作答；可主动查看详细训练记录，无需学生逐次授权；仅私密每日总结按学生对具体家长的单独授权开放 |
| 家长推送可见性 | 家长推送默认对学生和所有已关联家长可见；创建家长拥有编辑、停用和删除权 |
| 推送作答可见性 | 学生的文字、图片、手写过程、心得与评论默认对所有已关联家长可见；不提供私密模式 |
| AI 与语音 | 当前不纳入设计；每日总结始终由学生自行书写，不作为模型输入。未来语音转文字优先评估本地部署模型，并另行讨论授权与架构 |
| 积分兑换对象 | MVP 只记录兑换/扣减申请与人工确认，不接入支付或实物商城 |
| 脑力训练定位 | 明确为训练与游戏化自我记录，不展示“脑年龄”或能力排名 |
