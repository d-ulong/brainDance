# ADR-0001：中国大陆优先部署

- 状态：已接受
- 日期：2026-08-25
- 决策者：项目负责人
- 复审触发条件：目标用户明显跨区域、活跃家庭达到 10,000、区域可用性/SLO 无法满足，或合规评审提出不同要求。

## 背景

首期面向中国大陆 5–18 岁家庭，处理未成年人资料、训练记录和家庭私密内容。访问体验、数据位置、供应商数据处理协议与本地运维支持具有实际约束。

## 决策

生产优先采用中国大陆单区域云的托管应用运行环境、托管 PostgreSQL 与独立 Worker。业务 Module 通过 Interface 接入基础设施，不依赖厂商 SDK；具体厂商、可用区、对象存储和消息实现另以 ADR 确定。

## 后果

- 有利于大陆访问体验和数据驻留治理。
- 首期接受单区域故障域风险，以 99.5% MVP 可用性、RPO≤24 小时、RTO≤4 小时和季度恢复演练约束；规模增长后复审多可用区与灾备。
- 增加供应商比较、DPA、未成年人数据处理和部署运维工作。
- 此决策不等于合规结论；上线前专业合规评审是阻断项。

## 被拒绝选项

- 全球托管全栈平台：上线快，但大陆访问、数据位置与供应商协议难统一。
- 立即多区域部署：恢复能力更强，但在尚未验证 MVP 前成本与运维复杂度过高。
