# ADR-0002：家庭作为时区与成员归属单位

- 状态：已接受
- 日期：2026-08-25
- 决策者：项目负责人
- 复审触发条件：需要支持重组家庭、多活跃家庭归属、可修改时区或跨学生共享计划。

## 背景

产品只服务家庭协作。一位家长可陪伴多名学生，一名学生可关联多位家长；日程、提醒、积分和家庭日期必须有统一解释。仅使用家长—学生边无法表达共享时区和多学生归属。

## 决策

家庭承载成员归属与固定 `Asia/Shanghai` 时区；首次生效亲子关系创建家庭，后续关系加入该学生已有家庭。MVP 中父母和学生均只能属于一个 active family，正式计划始终只归一名学生。

`relationships` 是亲子协作和授权的权威事实；`family_memberships` 是由有效关系派生的成员投影，不能独立授予访问。部分解除只移除对应关系；只有最后一条家长关系结束才形成无家长家庭。

## 后果

- 日程和积分日期具有稳定含义，家庭内无需个人时区换算。
- 多家长和多学生可以共享家庭，同时保持单学生计划、执行记录和积分隔离。
- 重组家庭、跨家庭家长、时区迁移和跨学生计划被明确延后。
- 解除关系、成员投影、私密授权撤销和授权纪元更新必须在一个事务中完成。

## 被拒绝选项

- 仅用家长—学生关系：无法稳定承载共享时区与家庭级成员归属。
- 允许学生同时属于多个家庭：会使时区、数据归属和撤权含义不确定。
- 每名用户独立时区或跨学生计划：会使提醒、日程日期、积分事实与执行记录难以解释。
