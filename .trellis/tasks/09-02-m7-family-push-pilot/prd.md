# M7 家庭推送试点

## Goal

让当前关联家长能够向指定学生发布家庭内学习内容，学生可提交版本化思考与结果，家庭成员可围绕推送评论；在不引入系统级推送、任意附件、视频或 AI 的前提下，验证内容协作、撤权和媒体安全闭环。

## Confirmed Facts

- M7 路线图要求在“错题”与“家长推送”中二选一；仓库已冻结家长推送术语、用户流程和媒体边界，因此选择家长推送。
- 任一当前关联家长可创建推送；目标学生和全部当前关联家长可见，创建家长拥有编辑、停用和删除权。
- 推送支持文本、原始外链和 JPG/PNG/WebP 图片；不抓取外链预览，不支持视频、PDF、压缩包、音频或任意附件。
- 学生作答支持文本、图片或手写图片，可多次补充并保留提交时间和版本；不提供私密模式。
- 当前关联家长可评论，学生可回复；主体只能编辑或删除自己的评论，家庭普通界面只展示最新版本。
- 图片单文件不超过 10MB，必须经过实际类型/尺寸校验、恶意文件扫描和图片重编码；日志、审计和错误不得包含正文或媒体链接。
- 删除后图片立即禁止普通访问；无其他引用的媒体在 90 天后物理清除，只保留无正文最小审计元数据。
- 创建家长离关联时，未发布预约推送自动取消；已发布历史保留给仍在家庭中的成员，离关联家长立即失去访问和编辑权。

## Requirements

### R-M7-01 推送所有权与状态机

推送以目标学生和创建家长为权威归属，支持 draft、scheduled、published、disabled、deleted/cancelled 等可验证状态。创建者可编辑未发布内容、预约或立即发布，并可停用/删除；其他关联家长只读。重复命令、并发发布/取消和 Worker 重试不得重复发布或通知。

### R-M7-02 家庭可见性与实时授权

所有推送、作答、评论和媒体读取均在服务端实时复核 active relationship、目标学生、账户冻结与 authorization epoch；列表或缓存只用于候选筛选。无权与不存在不得泄露资源存在性。家庭推送不提供私密模式。

### R-M7-03 学生版本化作答

目标学生可对已发布且 active 的推送提交文本、图片或手写图片，并可多次补充。每次提交创建不可覆盖的版本并记录时间；家长只能读取。停用或删除推送后拒绝新作答。

### R-M7-04 家庭评论

当前关联家长可评论，目标学生可回复。评论创建者只能编辑/删除自己的评论；编辑保留审计版本，家庭普通读取只展示最新正文。删除后家庭仅见删除标识，正文不进入普通日志或审计 payload。

### R-M7-05 图片安全与访问

上传只接受 JPG、PNG、WebP，单文件最多 10MB；服务端校验声明类型与实际内容，经过恶意文件扫描和重编码后才进入可读状态。原始上传不得作为家庭可读对象。媒体访问使用短时、资源绑定、实时授权的读取能力，不返回永久公开链接。

### R-M7-06 删除、撤权与媒体生命周期

推送/作答删除后立即撤销正文和媒体普通访问；引用归零的媒体进入 90 天清理队列并由幂等 Worker 物理清除。学生账户删除/tombstone 必须覆盖 M7 正文、评论和媒体；恢复先重放 tombstone/撤权，再重建可重建状态。

### R-M7-07 预约发布与站内通知

预约发布复用既有 outbox/Worker 的租约、幂等和 dead/replay。发布、作答和评论只产生不含正文、链接、图片地址、计划名或积分信息的站内通用通知；不发送浏览器、短信、微信或邮件业务推送。

### R-M7-08 UI 与可观察性

家长和学生在 desktop Chromium 与 360×800 视口完成创建/预约/发布、阅读、版本化作答、评论、停用/删除及错误恢复主路径；状态不只靠颜色，危险删除有明确确认，无横向滚动。失败与 dead event 有不含正文的诊断证据。

## Acceptance Criteria

- [ ] AC-M7-01：所有权、状态转换、立即/预约发布、幂等重试及并发冲突由数据库约束和真实 PostgreSQL 测试固定。
- [ ] AC-M7-02：学生与多家长授权矩阵、离关联、冻结、越权和不存在资源均实时复核且不泄露。
- [ ] AC-M7-03：学生作答版本不可覆盖，重复提交安全重放，家长无法改写；停用/删除后拒绝新作答。
- [ ] AC-M7-04：评论创建、编辑、删除和回复权限完整；普通读取只见最新版本或删除标识，审计/outbox 不含正文。
- [ ] AC-M7-05：图片类型、10MB 上限、扫描、重编码、原始对象隔离、短时授权读取及异常文件拒绝均有自动化证据。
- [ ] AC-M7-06：删除/离关联立即撤权，90 天孤儿清理幂等；账户删除、tombstone 重放和恢复后已删 M7 正文/媒体不可读。
- [ ] AC-M7-07：预约 Worker 重试/dead replay 不重复发布或通知；站内通知仅含通用文案且系统级渠道未启用。
- [ ] AC-M7-08：desktop Chromium 与 mobile-360 完成联合主路径和关键失败路径，无横向滚动。
- [ ] AC-M7-09：migration、相关并发/授权/媒体测试、全量 test、typecheck、lint、format、build 和双视口 E2E 串行通过。

## Out of Scope

- 错题库、知识图谱、AI/语音、自动摘要、推荐或内容审核模型。
- 视频上传/嵌入治理、外链预览抓取、PDF、压缩包、音频及任意附件。
- 系统级浏览器、短信、微信或邮件业务推送；站内通知之外的渠道 Adapter。
- 私密推送/作答、家庭外分享、公开内容流、搜索、举报/申诉和管理员日常浏览正文。
- 生产媒体供应商绑定、DPA、驻留、密钥或真实生产部署；这些保持上线 blocker。

## Key Decisions

- 先交付文本/链接、预约、作答、评论和通知闭环，再接入图片媒体安全；两阶段分别固定 SHA 审核。
- 复用 outbox、实时家庭授权、冻结 guard 和 tombstone 顺序；媒体使用独立生命周期 seam，不复用导出 artifact 的一次性下载业务语义。
- 外链只保存和展示原始 URL，不进行服务端抓取。
