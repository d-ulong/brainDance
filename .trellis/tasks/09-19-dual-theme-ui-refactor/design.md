# 设计与不变量

## Authority

后端 service、现有 DTO、授权结果与业务规格为事实源；HTML 只决定视觉和信息层级。首页从已有日程读取源组织下一未完成日程，按实际日期/时间及现有状态排序，不解析展示文字或创造状态。若现有接口无法提供必要数据，记录精确缺口，不擅自新增 API。Asia/Shanghai 日期口径不变。

## 页面结构

学生：简洁品牌栏→日期问候→下一任务→今日安排→积分/训练。桌面主辅分栏，手机单列+底部主导航。主题插画集中于主任务、空状态、完成反馈，训练刺激区无装饰干扰。

家长：桌面约 224px 侧栏，主区顶部对象选择/页面标题/单个主操作，学生管理为紧凑列表，学生详情保持明确身份上下文；手机底部主导航，管理功能使用明确可见入口或带文字的更多。所有现有入口建立新旧对应表，不按猜测删减。

日程：手机日期条、当天统计、任务列表；周/月在屏宽内选择日期，选中后显示对应列表。桌面保留网格，以显示区域定位而非过滤删除凌晨任务。长标题允许换行或通过详情完整查看。

计划：桌面行列表、手机紧凑卡片；名称/对象/有效期/生成摘要清楚。独立编辑页复用现有字段和校验，以明确 query/path 承载编辑对象，服务端仍重新授权；旧编辑入口接入新页。保存、绑定、生成必须保持各自事务边界和错误恢复，不自动连写。

训练：只调整准备文案布局、外壳留白和非刺激控件。Stroop 颜色、反应刺激区域/时序、数字显示/回忆、键盘规则、随机化、失焦、年龄档、计分均原样保留。导航调整必须复用现有会话终止/离开保护。

## 组件与样式

优先改造 `src/components/ui/page-shell.tsx`、`top-tabs.tsx`、`app-theme.tsx`、学生/管理导航、modal/confirm/error dialog 与 `src/app/globals.css`；页面入口以真实路由为准。计划/日程复用 `src/components/schedule/`，训练复用 `src/components/training/`。

保留 BrainDance 标志和本地字体栈，不因未完成 Figma 稿引入 Noto 字体下载。提取 HTML SVG 作为本地资产/组件；装饰 aria-hidden。共享语义 token 管颜色/背景/边框/焦点，主题独立定义材质、圆角与阴影；状态语义色与训练刺激色分离。保留 `braindance-theme`、space/candy 取值和异常 storage 降级；主题恢复从外壳初始化，不能依赖主题按钮恰好挂载。主题偏好入口在个人页，两角色均可找到。

按引用范围合并冲突 CSS，禁用不断在文件末尾追加覆盖的修复方式。布局类型区分窄表单、阅读详情、宽工作台；安全区、软键盘、底部导航与固定保存栏不得互相遮挡。prefers-reduced-motion 下减少装饰动效。

## 资源、并发与失败

读取切换学生/日期时取消或忽略旧请求，最后选择的上下文胜出；卸载清理监听/定时器。主题切换不得触发业务写入。保存中禁止重复提交；失败保留草稿并展示原错误；既有幂等键/冲突码处理不改。空结果不是空数据库，网络失败不是余额零。无权限不展示缓存中的其他学生数据。

| 并发/错误场景 | 断言 |
|---|---|
| 快速切换学生 A→B 或日期 D1→D2，旧响应晚到 | 只显示 B/D2，操作对象也一致 |
| 双击保存、生成、完成 | 不新增并行重复写；复用原防重语义 |
| 保存中返回/关闭，保存失败 | 不静默丢草稿或误报成功；保留可恢复操作 |
| 训练中导航/返回/主题入口 | 现有离开保护和终止行为保持，刺激时间不重置 |
| 401/403、空数组、网络失败、搜索无匹配 | 四类状态正确且互不混淆 |

## 回退边界

只含 UI、资产及聚焦测试，不含数据迁移。审核不通过集中整改一次；不自行 reset/revert。Codex 按实现 SHA 复核后决定是否放行。
