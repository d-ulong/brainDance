- 新建成功只创建一个计划；之后保存更新相同 id，并使用最新 revision。推荐转入已有编辑页复用状态与启用入口，或在原页明确切换为已有计划状态；两种均不得丢字段或失去原启用能力。

| 场景 | 必须满足 |
|---|---|
| 新建→保存→改名→再保存 | 仅一次创建，其余更新同一 id，最新 revision 正确 |
| 保存→修改→启用 | 未保存修改被保留，未调用旧定义启用，明确提示先保存 |
| 延迟保存响应期间尝试修改→回包→离开 | 要么字段明确不可编辑，要么后改内容仍 dirty 并确认，不能静默丢失 |

| 绑定 A 成功 B 失败，随后直接重试 | 保留 B 待完成选择，重试不重复 A；定义草稿不变 |
| 绑定成功后重读失败 | 反馈区分成功写入和读取失败，不清除待确认目标，恢复后以事实为准 |

| Modal 连续输入/叠加错误弹窗 Escape | 不跳焦点，仅关闭顶层，不丢底层草稿 |
