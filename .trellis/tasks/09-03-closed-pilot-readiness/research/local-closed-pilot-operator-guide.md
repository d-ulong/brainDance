# 本机封闭试点操作手册

## 范围与地址

- 仅限当前电脑本机使用；不要把服务暴露到局域网或公网。
- 开发服务地址：`http://localhost:3002`
- 家长注册：`http://localhost:3002/register`
- 管理员邀请码管理：`http://localhost:3002/admin/invitations`

## 一次性准备

1. 确认已安装 Node.js 20+、pnpm 和本机 PostgreSQL，且 `DATABASE_URL` 指向专用于本机试点的数据库。
2. 在仓库根目录安装已锁定依赖：`pnpm install --frozen-lockfile`。
3. 执行迁移：`pnpm db:migrate`。
4. 仅在隔离试点库中初始化管理员与训练定义：设置 `SEED_ADMIN_EMAIL` 和 `SEED_ADMIN_PASSWORD`，再执行 `pnpm db:seed`。密码只能通过受控环境变量或密码管理器提供，禁止写入本文档、聊天、日志或代码。

## 启动与关闭

启动（在仓库根目录的一个终端中）：

```powershell
.\scripts\start-closed-pilot.ps1
```

看到 Next.js 显示服务已监听 3002 后，浏览器访问 `http://localhost:3002`。该终端必须保持运行。

脚本仅在当前进程中把 `DATABASE_URL` 指向 `braindance_closed_pilot_20260903`，不修改 `.env.local` 或旧 `braindance` 数据库。首次准备仍须在该隔离库上执行迁移和初始化；常规重启不需要重复 seed。

关闭：前台启动时在同一终端按 `Ctrl+C` 一次，等待进程退出。若服务由后台维护者启动，先确认监听 3002 的 PID，再只结束该 PID；不要结束 PostgreSQL 或删除数据库来关闭 Web 服务。

## 首次试点操作

1. 使用受控保存的管理员邮箱、密码及系统要求的 TOTP 登录首页。
2. 打开 `/admin/invitations`，选择目标角色生成邀请码。封闭试点只生成最少数量、单次使用的家长邀请码；过期或不再需要时立即撤销。
3. 邀请码只显示一次：通过受控的一对一渠道发送给受邀家长；不得放入群聊、文档、仓库、日志或截图。
4. 家长打开 `/register` 注册并完成联系方式验证；首位家长关联学生时必须完成版本化监护同意留存。
5. 试点结束、受邀人退出或发生安全疑虑时：撤销未使用邀请码，结束相关家庭关联或按删除流程处理，并保留不含正文/密码/邀请码的审计证据。

## 快速故障定位

| 现象 | 检查与处理 |
| --- | --- |
| 浏览器显示“localhost 拒绝连接” | 在仓库根目录运行 `./scripts/start-closed-pilot.ps1`；若终端已在运行，确认其输出没有报错且监听端口为 3002。 |
| `pnpm dev` 启动失败 | 先检查 `.env.local` 中的 `DATABASE_URL` 是否指向本机隔离试点库；不要在聊天中粘贴连接字符串。再运行 `pnpm db:migrate`，保留脱敏错误摘要。 |
| 3002 已被占用 | 停止占用 3002 的本机开发进程，或先向维护者报告；本试点不自行改端口，以免操作手册和访问地址失效。 |
| 管理员无法生成邀请码 | 确认已登录管理员账户且已完成要求的 TOTP；不要直接向数据库插入邀请码。 |
| 邀请码失效或泄露 | 立即在管理员页面撤销，重新生成单次邀请码；不要尝试恢复或复用旧码。 |

## 需要操作者配合的事项

- 确认本机隔离试点数据库名称和备份/恢复责任人。
- 以受控方式保存管理员密码与 TOTP，并决定谁有权生成/撤销邀请码。
- 审阅并确认试点用的监护同意、隐私告知和参与说明后，再邀请真实家庭。
- 若实际运行恢复演练或试点结束清理，需要明确授权；本手册不授权清除数据库或用户数据。
