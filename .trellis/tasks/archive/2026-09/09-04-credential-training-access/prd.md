# 凭据体验与家长训练访问

## Goal

统一注册与改密的密码规则和交互，并让家长能够进入独立的训练中心完成训练，而不污染学生的训练事实、趋势或积分。

## Confirmed Facts

- 当前注册页仅有一个密码字段；学生改密 Route/页面存在，但家长/管理员没有同等入口。
- 当前训练 session、metric 与 projection 都以 `studentId` 为权威归属；训练趋势、日有效资格和积分语义均建立在学生模型上。
- 现有训练客户端路由只指向 `/student/training/*`，家长现有训练页只读取指定学生的训练记录。

## Key Decisions

- 家长训练使用固定 `adult` 档的现有训练协议；记录和趋势仅属于该家长本人。
- 家长训练绝不产生积分、计划/日程完成事实、家庭推送事件或学生可见数据。
- 密码无需特殊字符；规则仅为 6–12 位且至少各含一位大写字母、小写字母和数字。

## Requirements

- R-CTA-01：注册、学生改密及新增的家长改密都要求密码 6–12 位，且同时含大写字母、小写字母和数字；服务端必须为权威校验。
- R-CTA-02：所有设置新密码的表单均要求重复输入并在提交前提示不一致；密码输入提供可访问的显示/隐藏切换。
- R-CTA-03：家长可进入训练中心并完成现有训练协议；其训练记录与学生记录、学生趋势、家庭计划和积分绝不混合。
- R-CTA-04：变更须有聚焦 DTO、Route、授权、数据库不变量和 desktop/mobile UI 证据。

## Acceptance Criteria

- [ ] AC-CTA-01：所有新密码入口对长度、大小写与数字以及二次确认表现一致；无效输入不写入密码哈希。
- [ ] AC-CTA-02：显示/隐藏控件具有可访问名称，且不改变密码值或提交语义。
- [ ] AC-CTA-03：家长能够创建、提交并读取自己的训练记录；不能读取/写入无关家长或学生记录，学生积分与日程不受影响。
- [ ] AC-CTA-04：迁移、聚焦自动化测试和双视口关键路径证明上述边界。
