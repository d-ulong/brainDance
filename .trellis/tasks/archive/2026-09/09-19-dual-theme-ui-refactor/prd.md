## 要求及验收

| ID | 要求 | 确定验收 |
|---|---|---|
| R01/AC01 | 深空探索站、奶油糖果工坊具备独立材质、圆角、按钮、导航、插画语言 | 与 HTML/PNG 对照；不能仅换颜色。两角色可切换；保留 space/candy 存储兼容与默认 space |
| R02/AC02 | 学生首页任务优先 | 360×800 有待完成日程时首屏展示下一任务名称、时间、入口；今日列表随后，积分与训练次要。用真实 DTO，示例的姓名/时间/120 积分不得写死 |
| R03/AC03 | 家长桌面侧栏与学生上下文 | 首页学生概览优先；当前学生/全部学生/个人资源持续可辨；手机主导航底部固定，次级入口可见或明确更多，保留全部现有功能 |
| R04/AC04 | 手机日程默认当天列表 | 日/周/月均可定位任意日期，周/月用于选日期与概览；不横拖宽网格找今天；桌面网格保留，初始定位相关时段，可访问完整 24 小时 |
| R05/AC05 | 计划列表紧凑、操作分层 | 首屏可见首项；搜索+筛选摘要，更多筛选可展开；保留编辑、预览、复制、对象维护、生成等既有入口，主要操作文字不被挤断 |
| R06/AC06 | 复杂计划独立编辑页 | 基本信息/任务内容/适用对象分组；高级设置收起不改值；每周星期选择；持续可达保存取消；未保存离开确认；旧入口和深链接可达 |
| R07/AC07 | 训练准备与进行态分开 | 准备页简明规则与开始入口；360×800 进行态刺激及必要控制可见，仍可明确结束；主题不得改变训练刺激、计时或评分 |
| R08/AC08 | 状态与可访问性 | 尚无数据、搜索无结果、加载失败、无权限分别呈现；清筛选/局部重试有效；弹窗焦点进入/圈定/返回、Escape 关闭或未保存确认；键盘和文字放大可操作 |
| R09/AC09 | 全站视觉一致 | 登录标题与表单同组；账号页按内容高度；共享壳、输入、按钮、弹窗/portal 均正确继承主题，主触控目标≥44px，正常正文对比度≥4.5:1，不能只靠颜色表状态 |
| R10/AC10 | 业务无回归 | 权限、积分、计划绑定/生成、训练终止、错误和重复提交语义不变；真实流程与视觉 mock 证据分开报告 |

## 不在范围

不更换技术栈/UI 库；不增加 AI、排行榜、诊断、购物；不改 schema/migration、API DTO、业务服务、计分/年龄档/训练算法。家长与学生的导出、兑换、推送等非核心页只适配共享外壳和组件并保留功能，不扩展业务。
