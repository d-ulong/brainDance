# 单次实施计划

用户已授权 Cursor 按本任务实施。唯一入口是 `cursor-instruction.md`，本文件为内部顺序，不构成多个交接阶段。

1. 核对 main、完整基线 SHA、工作区；读前端规范和本任务；浏览 HTML 与 PNG；记录现有路由/功能/DTO 到新布局映射。
2. 建主题 tokens 与共享组件、壳和导航；同时考虑 portal、存储恢复、焦点和手机安全区。
3. 学生首页与家长管理；计划/日程和完整编辑页；训练准备/专注布局；登录与个人页收敛。
4. 聚焦验证，生成同内容前后截图和 AC 对照记录；交审核。

## 验证

共享外壳跨多个模块，必须 `pnpm typecheck`、针对变更文件 ESLint/Prettier，及受影响 UI/导航/编辑/训练生命周期聚焦测试。不机械全量测试/build。

视觉矩阵：1440×1000、390×844、360×800；768×1024 补查导航断点；双主题×两角色。覆盖学生首页、家长首页/学生管理、计划列表/编辑、手机日/周/月、三种训练准备/进行态、登录/个人页；检查空数据、筛选无结果、读取失败、长标题、多学生、多任务、键盘、200%文字缩放、软键盘、底栏遮挡。训练实际行为必须用聚焦回归，不仅截图。

优先以浏览器 mock 验证视觉，录明 mock 不证明后端业务。现有 `capture.cjs --sample` 可参考，但修改 DOM 后须适配而非当作通用验收。截图库/临时 JSON 先写系统临时目录，完成后归档，避免触发 Next HMR。

真实写流程只能使用已核对隔离测试库/账号。不得直接运行会 reset/TRUNCATE 的全量 E2E setup；不得隐式继承 `.env.local` 指向试点库。无安全环境时完成不依赖 DB 的检查，准确报告阻塞，不宣称全绿。dev 服务运行时不得同目录 build；不运行 migrate/seed/reset。
