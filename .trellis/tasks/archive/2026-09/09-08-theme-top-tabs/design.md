# 主题与顶部页签改造：技术设计

## Boundaries

- 新增客户端主题状态与导航组件，放在 `src/components/ui/`；页面继续通过 `PageShell` 接入，避免逐页复制导航或主题逻辑。
- 主题是表示层状态：浏览器 `localStorage` 保存值，根元素以 `data-theme` 承载；默认值为 `space`。服务端、数据库、认证、DTO 和 API 均不改变。
- `PageShell` 组合主题控制、角色页签、现有标题/返回/退出和内容区。未认证、联系方式待验证、改密页面不出现角色页签。

## Theme contract

`ThemeName = "space" | "candy"`，唯一持久化键使用集中常量。客户端首次 hydration 后读取该键；不存在、非法或读取失败时回落到 `space`。切换即更新根元素及本地存储，不刷新页面。

全局 CSS 定义两组语义 token（页面底色、表面、文字、弱文字、边框、主色、强调色、成功/警示色）和共享圆角/阴影。`PageShell` 与共享表单原语使用 token 化类名；常见卡片和按钮在 shell 边界内获得统一主题外观。训练刺激的颜色语义、状态文字和高对比操作区保持原有可读性，不能被装饰性配色覆盖。

## Navigation contract

`TopTabs` 客户端组件通过现有 `fetchSession()` 与 `usePathname()` 解析当前角色和路径，使用单一角色路由表决定可见页签、图标、文字、当前状态和 `data-testid`。路由表至少覆盖：

- 学生：主页、今日日程、训练中心、家庭推送、积分兑换、个人设置入口。
- 家长：主页、家长训练、学生、关联/创建学生入口、个人设置入口。
- 管理员：主页、邀请码。

动态学生详情页按所属顶层学生页签高亮；学生专属子页保留已有返回/上下文链接。窄屏容器使用横向滚动并隐藏滚动条视觉噪音，页签本身维持可点击触控面积。当前项同时使用 `aria-current="page"`、文字与形状变化，不能只依赖颜色。主题开关有可见文字和可访问名称。

## Training leave contract

训练 runner 向 `PageShell` 显式传入离开 guard。用户点击顶部页签或返回链接时：

1. 显示离开确认；取消时不导航。
2. 确认后调用既有 `POST /api/training/sessions/:sessionId/terminate`，以 `cancel` 完成当前 active 会话，再导航。
3. 取消失败时展示错误并留在训练页；提交中、已终止或出现原有错误时不重复终止。
4. `beforeunload` 仅提示浏览器级离开风险，不能伪造成功终止；原有失焦、恢复、事件队列和提交幂等语义不变。

该操作复用现有服务 authority 与终止状态机，不增加新的会话状态或 API。

## Compatibility and rollback

- 现有链接 URL、测试 ID、角色/联系验证/改密 gate 与 API 保持兼容。
- 主题偏好为可忽略的浏览器值；删除该键即恢复默认太空主题。
- 新 UI 仅在 `PageShell` 边界整合，回滚可通过撤回该变更恢复，无数据迁移。
