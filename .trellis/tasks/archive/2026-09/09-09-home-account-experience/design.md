# 设计

共享 PageShell 提供 Logo/顶栏/页签、紧凑标题与折叠说明；首页使用独立 dashboard 组件与既有授权 API，局部错误不能伪装为无数据。个人信息只从本人 session DTO 返回。

注册复用现有 invitation 事务；显式 role 只能 parent/student，学生使用 username/birthDate。按幂等键事务锁+邀请码行锁防重放超发，角色与输入绑定验证；不新增 schema。

在 family-access 中复用关系建立事务 helper；家长创建持有 parent 行锁，账号与关系同一事务；监护同意明确由创建者操作证明，不伪造学生确认。增加关系纪元后 route 刷新当前家长 cookie。新创建学生无需关联码；历史未关联账号不自动推断归属。

登录策略：默认保护不变；仅非 production、NEXT_PUBLIC_APP_URL loopback 且显式 LOCAL_PILOT_MODE=true 采用较短等待。客户端 ref 防重复请求、密码显示，服务器按剩余时间提示；锁到期记录解锁后重算，避免旧失败立即重锁。

密码运维脚本强校验 loopback 与精确库名，先预览数量后显式 apply，事务锁所有目标账号，逐个哈希、更新凭据/纪元/解锁并删除会话；记录不含密码的审计和解锁安全事件，保留禁用状态/删除冻结。临时统一密码仅这次授权的本机操作，不改注册密码政策。

## 2026-09-11 家长端信息架构改版

基于已登录实机巡检，家长端统一采用“品牌与全局导航 / 紧凑页标题与唯一主操作 / 页面专属工具栏 / 宽容器内容区”的四层结构。桌面内容区为居中宽版（最大 72rem），计划和推送采用自适应双列卡片；移动端收为单列而不横向溢出。

计划卡片以“计划名称、内容数、绑定学生、摘要、主操作 + 次操作”组织，推送卡片使用相同的卡片骨架。筛选收敛成低视觉重量的工具栏。两套主题仅替换语义色 token，不能改变布局与信息层级。全局导航、表单语义、既有 testid 与业务调用保持不变。
