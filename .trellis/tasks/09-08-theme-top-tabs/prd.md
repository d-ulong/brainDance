# 主题与顶部页签改造

## Goal

将现有偏中性的移动端页面改造为适合 5–18 岁家庭使用的活泼界面，并让已登录用户在主要功能间通过持续可见的顶部页签切换，无需反复返回首页。

## Confirmed facts

- 产品现有页面由 Next.js App Router 与 Tailwind CSS v4 构成，主要 UI 页面均为客户端组件。
- `PageShell` 是共享页面容器；当前首页以纵向链接承担角色入口，其他页面多只显示返回链接。
- 用户确认保留两套可手动选择的主题：糖果游乐园与太空探险队；太空探险队为默认主题。
- 主题选择只保存在当前浏览器；不在账号、数据库或 API 中同步。
- 训练页包含计时与会话生命周期，导航改造不得丢失、重复提交或绕过训练中断保护。

## Requirements

- R1：提供“太空探险队”与“糖果游乐园”两套完整视觉主题；默认使用太空探险队。
- R2：主题应使用更丰富但可读的颜色、柔和圆角、可爱且有明确文字的按钮与少量装饰性图标，覆盖共享容器、卡片、表单、提示与主要动作。
- R3：已登录学生、家长和管理员在主要功能页均拥有持续可见的顶部页签；页签按角色展示可访问的功能并标出当前项。窄屏可横向滚动，不出现页面横向溢出。
- R4：主页保留为各角色概览，而不再是唯一菜单入口；从任一主要页签可直接切换到其他主要功能。
- R5：训练进行中离开训练页前须进行确认；保留现有训练会话的终止、恢复和提交语义。
- R6：登录、注册、联系验证与改密等非主工作区页面沿用主题视觉，但不显示需要已登录会话的顶部页签。
- R7：不改变既有 API、数据库、权限、路由语义或业务文案；导航只展示当前角色已具备权限的入口。

## Acceptance criteria

- AC1：首次访问未设置主题时显示太空探险队，用户可以从可发现的主题控制项切换到糖果游乐园。
- AC2：学生、家长和管理员登录后，在主页及各自主要功能页均可见对应顶部页签，当前页签有文字和非颜色提示。
- AC3：360px 宽度下页签可操作且页面不产生横向滚动；所有图标按钮具备可访问名称。
- AC4：训练中触发页签切换时显示离开确认；取消后仍停留在训练，确认后按现有安全流程离开。
- AC5：既有主要业务导航和训练 E2E 流程保持通过，并补充主题/页签/训练离开保护的聚焦覆盖。

## Out of scope

- 新增主题插画素材、音效、动画系统、后端账户主题偏好、业务规则或权限模型调整。
- 改写路由路径、训练定义、积分、日程、推送或数据内容。
